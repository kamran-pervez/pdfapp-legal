## Enable GitHub Pages

1. Push to the branch GitHub Pages deploys from.
2. GitHub → **Settings** → **Pages** → confirm branch/folder.
3. Open:
   - https://kamran-pervez.github.io/pdfapp-legal/privacy.html
   - https://kamran-pervez.github.io/pdfapp-legal/terms.html
